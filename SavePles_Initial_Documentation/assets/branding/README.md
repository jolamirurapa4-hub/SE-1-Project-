# SavePles emblem

The approved initial emblem is [saveples-logo.png](saveples-logo.png).

It uses a black field, a white outline of the supplied traditional building reference, and a circular border with tapa-inspired motifs from the supplied pattern reference. The emblem contains no lettering. Write the product name as **SavePles** in accompanying text.

## Usage

- Preserve the original proportions and artwork.
- Keep the emblem on a black or compatible dark field.
- Leave clear space around the outer circle.
- Use the full-resolution PNG for documentation; validate readability before producing small icons.
- Do not imply that the emblem grants endorsement from a community or institution.

The project requester approved this version on 12 November 2026. Specific cultural attribution, permissions and suitability for public branding remain to be confirmed before public launch. No ownership or endorsement of the source traditions is asserted.
